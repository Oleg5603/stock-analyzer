# Stock Analyzer

Локальный учебный инструмент для проверки российских акций по конспекту стратегии активного инвестирования. Он импортирует реестр компаний, показывает цепочку правил и **не подключается к QUIK, не получает котировки и не отправляет торговые заявки**.

## Запуск

Требуется Python 3.11+.

```powershell
cd C:\Users\HP\Documents\Project\stock-analyzer
python -m pip install -r requirements.txt
python -m stock_analyzer self-test
python -m stock_analyzer serve --port 8765
```

Откройте `http://127.0.0.1:8765`. Загрузите CSV с обязательными колонками `ticker`, `name`, `sector`; шаблон находится в `data/sample_companies.csv`.

## Что проверяет v0.2

- назначенную пользователем категорию 1–4 и рекомендуемый диапазон веса;
- фундаментальный фильтр (отдельно для банков);
- D1 по публичным дневным свечам MOEX: закрытие выше SMA 50 и максимум последних 20 торговых дней выше максимума предыдущих 20;
- доступные без авторизации показатели МСФО с публичной страницы Smart-Lab, с датой отчёта и ссылкой на источник;
- отдельную загрузку краткосрочного долга из PDF только с подтверждённой страницы эмитента; при нечитабельном PDF или непроверенных единицах она оставляет статус «нужна проверка»;
- явное подтверждение H4 и Volume Profile;
- лимит сектора 20% с учётом предлагаемого веса.

Статусы: «Аналитический кандидат», «Нужна ручная проверка» и «Отклонить». Это не инвестиционная рекомендация.

## Границы методики

Не формализованы и поэтому отмечаются ручной проверкой: H4, построение объёмных зон, стоп-лосс, максимальная просадка, усреднение и итоговый лимит портфеля. Для категории 3 установлен порог Долг/EBITDA до 4: в источниках встречается противоречащий вариант 3,5; он зафиксирован в `docs/strategy-v0.1.md`.
